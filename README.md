## OpenExam Hub

[OpenExam Hub](https://openexam-hub.vercel.app) is a free, MIT-licensed study-roadmap platform for language exams such as TCF, IELTS and Goethe-Zertifikat. It turns official free material from exam boards and public broadcasters into a day-by-day plan. Every resource link is checked before you see it. No account is required.

The project started as a kitchen-table tool while my wife was preparing for her language exams.

- Live site: [openexam-hub.vercel.app](https://openexam-hub.vercel.app)
- Source: [JadissEL/openexam-hub](https://github.com/JadissEL/openexam-hub)

The study tools stay free. A few ads may appear on the planner (never on the landing page) until a publicly tracked funding goal is met; then the site is intended to become ad-free. If the project helps you, you can support it here:

- [Ko-fi](https://ko-fi.com/openexamhub)
- [Open Collective](https://opencollective.com/openexam-hub) (application pending)
